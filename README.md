# Site Institucional — Advocacia Especializada

Plataforma web institucional e de atendimento fiduciário desenvolvida em arquitetura moderna com React 19, Vite e Tailwind CSS.

## Requisitos
- Node.js 20+ (recomendado LTS)
- npm ou compatível

## Execução em Desenvolvimento

```bash
npm install --legacy-peer-deps
npm run dev
```

Acesse em: `http://localhost:3000`

## Build de Produção

```bash
npm run build
npm run preview
```
